# Lab 4: Directory Operations

## Commands: mkdir, rmdir

## mkdir (Make Directory)
Creates new folders.

Example:
```bash
mkdir my-project
mkdir -p projects/backup/old-files
```

## rmdir (Remove Directory)
Deletes empty directories only.

Example:
```bash
rmdir my-folder
```

## Key Points
- mkdir creates folders
- rmdir only works on empty folders
- Use mkdir -p for nested folders
