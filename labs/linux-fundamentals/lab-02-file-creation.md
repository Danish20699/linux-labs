# Lab 2: File Creation & Reading Commands

## Commands Covered
- touch - Create empty files
- echo - Print text
- cat - Read file contents
- > - Redirect to file
- >> - Append to file

## 1. touch (Create Empty File)
Creates a new empty file.
Example: touch deleteme.txt

## 2. echo (Print Text)
Outputs text to screen.
Example: echo "Hello Linux!"

## 3. > (Redirect Output)
Puts output INTO a file (OVERWRITES!)
Example: echo "Hello" > file.txt

## 4. >> (Append to File)
Adds text to END of file (doesn't overwrite!)
Example: echo "Line 2" >> file.txt

## 5. cat (Read Files)
Displays file contents.
Example: cat test-file.txt

## Key Tip
Use >> (append) to keep old content!
Use > only when you want to overwrite!
