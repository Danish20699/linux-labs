# Lab 10: File Management Commands

## Commands
- find - Find files by name/type
- locate - Fast file search
- which - Find command location
- file - Show file type

## find

```bash
find /home -name "*.txt"
# Find all .txt files
```

## locate

```bash
locate filename
# Fast search (uses database)
```

## which

```bash
which python
# Shows path to command
```

## file

```bash
file document.pdf
# Shows file type
```
