# Danish Nazir - DevOps Portfolio Website

## Lab 22: Final Project

A dynamic, database-driven portfolio website built using PHP, PostgreSQL, and Apache.

## Live URL (Local)
http://localhost:8080/index.php

## Architecture

Browser -> Apache -> PHP -> PostgreSQL -> Dynamic HTML

## Pages

1. index.php - Homepage with hero section
2. skills.php - Displays 10 technical skills from database
3. projects.php - Shows work experience dynamically
4. education.php - Displays education background

## Database Structure

### Database: portfolio_db

### Tables:
- skills (id, skill_name, category)
- projects (id, title, description, duration)
- education (id, degree, institution, duration)

## Technologies Used

- Linux (Ubuntu)
- Apache Web Server
- PostgreSQL Database
- PHP Backend
- Modern CSS (Gradients, Glassmorphism)

## Security

- Dedicated database user (portfolio_user) with limited permissions
- Not using postgres superuser
- Following least privilege principle

## Design Features

- Gradient background (blue theme)
- Card-based layout with hover effects
- Glassmorphism (frosted glass) styling
- Responsive grid for skills
- Professional navigation

- Full-stack development

- Debugging production errors
